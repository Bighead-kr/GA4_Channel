# 시각화 스펙 — Tableau Public 4화면

**대상 결론:** 유입 채널은 볼륨이 최대 7배 갈리지만, 진입·퍼널·구매 가치·리텐션 어느 지표에서도 채널 간 유저 질 차이가 없다. 지렛대는 채널 재배분이 아니라 전 채널 공통의 퍼널 이탈 구간과 주간 재방문율이다.

## 공통 규칙

| 항목 | 값 |
|---|---|
| 도구 | Tableau Public |
| 채널 정렬 | 유입 볼륨 내림차순 고정: Organic Search → Direct → Unknown → Referral → Self-referral → Paid Search. 모든 화면 동일 (`channel_order` 필드 사용) |
| 채널 색 (엔티티 고정, 순위 아님) | **Organic Search / Referral / Paid Search** = 각각 구분되는 채도 있는 색 3개. **Direct / Unknown / Self-referral** = 회색. 색은 화면 2·3에서 동일하게 유지 |
| 왜 회색인가 | Direct = 돈으로 못 사는 채널(북마크·앱·추적유실). Unknown = 난독화로 채널 미상 18.5%. Self-referral = 크로스도메인 추적 결함. **셋 다 "예산을 옮길 수 있는 채널"이 아니고, 지표 차이도 이 셋에서만 나온다(추적 손상)** — Phase 1 참고 |
| 축 | 화면당 축 1개. 이중축(y축 2개) 금지 |
| 라벨 | 값 라벨은 선택적으로 — 양 끝점·강조 대상에만. 모든 점에 숫자 X |
| 범례 | 2개 이상 시리즈면 범례 필수 |
| 폰트/그리드 | 그리드·축은 옅게(보조), 데이터가 주역 |
| 대시보드 | 4화면 2×2. 대시보드 제목 = 결론 한 문장. 각 화면 상단에 그 화면의 한 줄 메시지 |

## 화면 1 — 채널별 유입 볼륨

- **데이터:** `volume.csv`
- **한 줄 메시지:** "Organic이 Paid의 7배를 데려온다"
- **마크:** 가로 막대 (Bar)
  - y = channel (channel_order 내림차순)
  - x = users
  - 색 = 단일 색 (전 채널 동일). 강조 불필요 — 길이가 메시지
  - 데이터 끝: 4px 라운드
- **라벨:** 각 막대 끝에 `users` + `user_pct%`. 맨 위(Organic 37.7%)·맨 아래(Paid 5.3%)만 굵게
- **주석:** "상위 3개 채널이 유입의 80%. 유료(Paid)는 5.3%뿐" (텍스트 박스)
- **툴팁:** channel / 유입 유저수 / 점유율 / 세션 수

## 화면 2 — 볼륨은 갈리고, 질은 안 갈린다 ★ 핵심

- **데이터:** `quality_dots.csv` (점 위치용), `metric_spread.csv` (요약 막대용)
- **한 줄 메시지:** "유입 유저수만 채널마다 크게 다르고, 나머지 5개 지표는 채널이 거의 겹친다"
- **마크:** Dot plot (한 지표 = 한 행, 채널 = 점)
  - y = metric (metric_order 순: 유입 유저수 → view_item 도달률 → 퍼널 전환율 → 주문금액 중앙값 → ARPU → W1 리텐션)
  - x = `pct_dev_from_mean` (채널 평균 대비 편차 %). **0 기준선 굵게.** 축 범위 -80 ~ +130 공통
  - 점 색 = 채널 색 규칙(위 공통). Direct/Unknown/Self-referral은 회색 점
  - 점 크기 ≥ 8px, 겹칠 때 2px 흰 링
- **읽는 법:** "유입 유저수" 행은 점이 축 전체에 흩어짐(-68% ~ +126%). 나머지 5개 행은 점이 0 근처에 뭉침
- **보조(권장):** 오른쪽에 작은 막대 하나 — `metric_spread.csv`의 `spread_spendable3_pp`(지출 가능 3채널 기준 편차 폭). 유입 유저수 = 186, 나머지 전부 ≤ 6. 이 막대 하나가 결론
- **주석:** "지출을 옮길 수 있는 3채널(Organic·Paid·Referral)만 보면, 볼륨은 186%p 갈리는데 나머지 지표는 전부 6%p 이내다. Direct·Unknown·Self-referral에서 보이는 편차는 채널 차이가 아니라 추적 손상이다(Phase 1)."
- **툴팁:** metric / channel / 실제값(raw_value) / 채널 평균 대비 편차
- **주의:** min–max 0~100 정규화 쓰지 말 것 — 모든 지표가 0~100을 꽉 채워 스프레드 차이가 사라짐. 반드시 "평균 대비 편차 %"

## 화면 3 — 채널별 퍼널 통과율

- **데이터:** `funnel.csv`
- **한 줄 메시지:** "채널선이 겹친다. 유저는 채널과 무관하게 같은 구간에서 샌다"
- **마크:** 라인 (Line), 채널별 1선
  - x = step (step_order: view_item → add_to_cart → begin_checkout → add_payment_info → purchase)
  - y = `pct_of_view_item` (view_item=100 기준 누적 통과율)
  - 색 = 채널 색 규칙. spendable 3 = 컬러 실선, 나머지 3 = 회색 실선
  - 마커 ≥ 8px
- **읽는 법:** 6개 선이 거의 포개짐. 가장 큰 낙차는 `view_item → add_to_cart` 구간(100 → 약 20). 모든 채널 공통
- **강조:** view_item → add_to_cart 구간을 배경 음영 + "최대 이탈: 80%가 여기서 이탈" 주석
- **보조:** `step_to_step_pct`(단계 간 통과율)로 같은 라인차트를 한 번 더 그려도 됨 — 단계별 병목이 더 선명
- **툴팁:** channel / step / 도달 유저수 / view_item 대비 % / 직전 단계 대비 %

## 화면 4 — 코호트 리텐션 히트맵

- **데이터:** `cohort.csv`
- **한 줄 메시지:** "W1에 95%가 이탈 — 재구매 없는 단발 방문 데이터셋"
- **마크:** 히트맵 (사각형)
  - 행 = cohort_week_start (유입 주, 5개: 11-01 ~ 11-29)
  - 열 = rel_week (W1 ~ W8). **W0(100%)는 제외** — 넣으면 색 스케일이 W1~W8을 못 살림
  - 색 = `retention_pct`, **단일 hue 순차 스케일**(연함 → 진함). 무지개 금지, 발산 스케일 금지
  - 셀에 `retention_pct` 텍스트 라벨
- **읽는 법:** W1이 4~5%, W4에 1% 아래, W8에 0.3%. 5개 코호트 행이 같은 패턴 = 계절성 없음
- **주석:** "채널별로 쪼개도 W1 재방문율은 4.0~5.3%로 동일(화면 2 참고). 관측 창 3개월 → W8까지만, 장기 리텐션은 결론 불가"
- **툴팁:** 유입 주 / 상대 주차 / 코호트 크기 / 재방문 유저수 / 재방문율
